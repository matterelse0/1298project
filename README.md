# USB Image Writer

Локальное Linux-приложение для записи дисковых образов на USB через `dd` и
создания Windows-флешек с WoeUSB-ng. Интерфейс работает в браузере, а движок —
на Python; внешние веб-сервисы и графические Python-библиотеки не используются.

**Запись полностью стирает выбранный накопитель.** Перед подтверждением внимательно
проверь путь, модель и размер диска. Сначала сохрани все нужные с него файлы.

## Запуск

Нужны Python 3, браузер, `sudo` и `util-linux`:

Команды ниже предназначены для Debian/antiX. В других дистрибутивах установи
эти пакеты через их пакетный менеджер.

```sh
sudo apt update
sudo apt install python3 util-linux sudo
python3 dd_writer.py
```

Приложение запустит веб-интерфейс и откроет его в браузере. Веб-сервер слушает
только `127.0.0.1` на случайном порту и работает, пока запущена команда. Чтобы
остановить его, нажми `Ctrl+C` в терминале. Если браузер не открылся, адрес будет
напечатан в терминале; не передавай этот адрес другим людям.

Для записи, размонтирования и установки системных зависимостей введи пароль
`sudo` в браузере. Он передаётся только локальному движку на время операции и не
сохраняется в файлах или журнале.

## Запись Windows ISO

Выбери **«Установщик Windows»**, затем нажми **«Установить WoeUSB»**. После
подтверждения и ввода пароля приложение установит необходимые системные
зависимости через доступный пакетный менеджер (`apt`, `dnf`, `yum`, `pacman`,
`zypper`, `apk` или `xbps-install`), создаст отдельное Python-окружение в
`~/.local/share/usb-image-writer/woeusb` и установит WoeUSB-ng от имени текущего
пользователя. Установщик скачивает исходники WoeUSB-ng 0.2.12 с PyPI, проверяет
контрольную сумму и устанавливает пакет в editable-режиме. Это обходит ошибку
upstream-инсталлятора, который при обычной установке пытается записать
`woeusbgui` в `/usr/local/bin`. Системные Python-пакеты не изменяются; кэш сборки
находится в `~/.cache/usb-image-writer/pip`. Для этого нужен доступ в интернет
и включённые репозитории с необходимыми пакетами. Если пакетный менеджер не
поддержан или пакет недоступен в репозиториях дистрибутива, причина появится в
журнале; зависимости можно установить вручную.

Кнопка **«Проверить»** запускает справку WoeUSB-ng и убеждается, что команда
записи `--device` доступна. USB-накопитель при этой проверке не изменяется.

На Debian/antiX зависимости можно установить вручную:

```sh
sudo apt update
sudo apt install python3-venv python3-wxgtk4.0 python3-termcolor \
  p7zip-full grub2-common grub-pc-bin parted dosfstools ntfs-3g
```

Затем вручную подготовь отдельное окружение и запусти установщик из каталога
проекта:

```sh
python3 -m venv --system-site-packages \
  ~/.local/share/usb-image-writer/woeusb
~/.local/share/usb-image-writer/woeusb/bin/python install_woeusb.py \
  --source-root ~/.local/share/usb-image-writer/source
```

После установки выбери режим «Установщик Windows».
WoeUSB-ng сам создаёт разметку и форматирует USB; существующие данные на
накопителе будут удалены. Проект заявляет поддержку Windows Vista–10, Legacy
BIOS и UEFI для Windows 7 и новее; для больших файлов WoeUSB-ng автоматически
выбирает NTFS и добавляет поддержку UEFI:NTFS. Для Windows 11 совместимость
зависит от конкретного ISO. См. [официальные инструкции WoeUSB-ng](https://github.com/WoeUSB/WoeUSB-ng).

Выбери образ через браузер или укажи его полный путь. При выборе файла в браузере
он копируется в `~/.cache/usb-image-writer/images`, поэтому проверь, что на диске
хватит места; ввод пути позволяет обойтись без копирования. Подключи USB и выбери
его в списке. Если разделы смонтированы, нажми **«Размонтировать»** и подтверди
действие; файлы при этом не удаляются.
Для обычных образов используется `dd`, а Windows ISO передаётся WoeUSB-ng.

Перед записью проверь выбранный диск и подтверди предупреждение. Программа
проверяет тип устройства, смонтированные разделы и расположение образа.
Журнал показывает ход операций и автоматически сворачивается через 3 секунды
после завершения. Не отключай USB до сообщения об успехе.
